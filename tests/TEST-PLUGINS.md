# 三种本地验收插件

双击项目根目录的 `查看界面.cmd`，即可打开最新已生成的本地验收界面，带三个测试插件。完成后便签消失，脚本结束。

在项目根目录执行（从 release 下的构建记录选择最新可用本地构建；首次使用前运行 npm run package）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/Start-TestPlugins.ps1
```

也可传入 `-PreviewDirectory '预览版所在目录'`。需要含最新配置界面功能的构建。

| 侧栏顺序 | 右键 | 左键执行结果 |
| --- | --- | --- |
| 网页配置 | 插件自己的网页：文字、颜色、大小、实时预览、保存 | 回显已保存的三个参数和运行次数 |
| 简单配置 | 宿主的“工具设置”表单：文字、次数、格式、显示计数 | 按配置输出文字 |
| 无需配置 | 仅查看结果，无配置表单 | 固定文字和递增计数 |

三个按钮的运行状态使用现有颜色；每次运行有约 450ms 延迟，便于观察。修改配置后保存，再左键执行验证效果。执行不会自动跳转页面。未保存的网页修改不会影响执行配置。

服务仅监听本机回环地址；不读取屏幕、剪贴板或用户文件。测试文件属于 `tests/`，不随产品打包。每次运行使用独立的 `.qa/acceptance-*/data`，不修改日常应用数据或插件。运行记录见 `.qa/acceptance-current.json`，计数随测试服务重启归零。

CLI 默认等待用户完成，没有用户操作时限。便签可以最小化到任务栏。完成或取消后便签立即消失，最后一项任务结束且响应传完后，桌面端自动退出，测试服务随后自动退出。没有主界面或托盘，也没有上传、提交或发布步骤。
