# human_cli 用户协助

human_cli 是 AI 请求用户协助操作的软件。AI 把需要人参与的步骤写到便签(内容会置顶呈现给用户)，用户操作软件、游戏或网页后，通过文字、图片、文件回复；AI 读取结果后接着完成原任务。

适用情形包括没有合适终端/API 的软件与游戏、需要用户现场判断的交互，以及用终端或代码操作较繁琐且容易出错的流程。网站人机验证应交给用户在原页面完成，回复完成情况即可。需要用户运行脚本或程序时，可以在便签侧栏挂载启动插件。

## 准备与选择入口

- 已连接 human_cli MCP 时优先使用其工具；否则使用已安装便携包的 `human_cli.exe`。工具名可能带客户端前缀，以实际工具目录为准。
- MCP/CLI 的调用、配置、完整参数示例与恢复方法见 [references/mcp-cli.md](references/mcp-cli.md)。只读取当前所需部分。
- 需要便签上的功能按钮，先查 `human_plugins` 或 CLI `plugins`；只绑定目录中实际存在且配置有效的插件。
- 需要编写脚本/程序以辅助用户操作(例如需要采集数据)时，读取 [references/plugins.md](references/plugins.md)。它包含 SPI 协议、可运行的 Python 启动提供者、旧插件格式与配置界面边界。
- 本 Skill 按 human_cli 2.0.3 的行为编写，对外回复 `schemaVersion` 为 `1`。客户端工具声明与安装版本不符时先检查版本和连接，不能虚构工具或参数。

## 写出用户可以直接执行的请求

说明当前卡在哪一步、要操作哪个软件/游戏/页面、需要用户做什么、最后回复什么。把定位路径、可见按钮文字和必要背景写清楚；步骤只覆盖需要人参与的部分。

例如：“请在当前浏览器完成页面的人机验证。验证通过后停留在结果页，回复是否成功；失败时附错误截图。”游戏操作可以写明进入的界面、需要尝试的动作和希望观察到的现象。

需要运行已有脚本或程序时，先准备可用的插件入口，让便签说明明确指向对应按钮；AI 不要在请求发出前代替用户点击或启动本应由用户决定的操作。绑定插件本身不会执行程序。按钮成功启动程序也不等于用户完成了任务。

## 请求、等待与恢复

1. 为本次逻辑请求生成唯一的 `idempotencyKey`；同一次创建重试保持原键，新任务使用新键。不要照抄示例键用于所有任务。
2. 正常调用 `human_request` 或 CLI `request`，默认在同一次调用中等待用户回复。只有明确需要后台创建时才使用 `background: true` / `--background`，然后对已有 ID 等待。
3. 不设置用户操作期限。最小化、用户打字或保存草稿都不会结束请求。宿主工具调用可能有自己的超时；CLI 长时间运行时保留执行会话，继续等待其输出。
4. 连接断开或 AI 重启后，保留已有 `requestId`，用 `human_get` 查看状态，再对 pending 请求恢复 `human_wait`。丢失 ID 时通过 `human_logs` 按标题、项目背景和创建时间定位；不要直接重复创建便签。
5. 只在协助目标发生变化时更新说明，携带 `human_get` 返回的当前 `version`。AI 不再需要协助时可取消已有请求。

## 理解用户交回的结果

- `completed`：按 `content[]` 原顺序处理 `text`、`image`、`file`、`diagnostic`，文字与附件的穿插有含义。MCP 外层只有一个 text 块，它的文本是回复 JSON；内层 `content[]` 才是用户内容。
- 图片和文件通过绝对 `path` 交付。使用自身文件/图片工具读取对应文件，不要求用户重新上传，也不要把未读取的附件当成已看过。默认不回传二进制、Base64 或 MCP 图片块。
- `submission.type = confirmation_only`：用户点击了完成，软件收到的正文与附件均为空。这不是验收通过的证据，也不能据此判断用户输入丢失。根据原请求判断是否足够继续。
- `cancelled` 且 `cancelledBy = user`：用户通过 ×、Alt+F4 或任务栏关闭了当前协助。结束这次等待，不自动新建同一便签。它与“－”最小化不同。
- `pending` 的草稿和工具结果是过程信息，不是正式回复。`human_get` 可查看完整快照，不能将其误当用户已提交。
- `replyState = discarded`：用户已经丢弃缓存回复，不继续使用旧内容冒充本次返回。

回复默认保存在软件目录的 `cache/<requestId>/`；环境变量可另行指定缓存根目录。`human_logs` 提供实际 `requestPath`、`replyPath`，以返回路径为准。文件路径属于 human_cli 所在机器；跨机器使用需要可访问的共享路径或额外文件传输，Skill 不会自动同步文件。

完成或取消后便签消失；最后一个任务响应传完，桌面端自动退出，下次调用按需启动。无需给软件发送“已收到”回执。向用户报告自己根据回复完成了什么，并将未验证的事项说清楚。
