# 界面迁移说明

视觉来源是用户提供的 `archive/prototype/rebuild/sticky-note.html`，原文件保留。它是独立浏览器演示；桌面实现位于 `src/`，连接现有 preload、请求服务和网络 SPI。

按用户选择，继续采用原来的小便签尺寸：默认原生窗口 380 × 360 DIP，中央区域约 320px 宽。拖拽调整、记忆位置尺寸、多显示器恢复规则沿用。迁移圆角外框与内纸面、系统字体、黑白主按钮、复选框反馈、真实任务进度、带边框回复框、附件名称及圆角工具栏。尺寸扩大时内容间距和文字适度放大；小尺寸下任务区滚动，回复框与完成按钮保持可见。

界面中的任务标题、步骤、描述、进度、附件及工具状态来自真实任务，不读取演示页面的 localStorage。项目仅在任务详情中查看。勾选步骤只记录进度，不成为用户完成操作的强制门槛。

右侧工具栏提供返回便签、插件按钮和设置；AI 绑定到左侧的插件仍显示在左侧。左键执行、右键或 Shift+F10 配置/结果的语义不变。网页配置仍嵌入隔离的原生 WebContentsView，简单配置仍由 Schema 生成，无配置插件不显示空表单。错误复制、附入回复、图片保存及工具结果保留。

设置页继续支持四种主题；新数据默认采用新稿的浅色，原有用户保存的主题保持。新增与演示对应的控件动效开关，并将它接入 `preferences.motion` 的持久化、校验和窗口广播。旧数据缺少此字段时按启用处理；系统减少动态效果设置仍然优先。置顶控制操作真实窗口。

演示外围的网页标题、工作区背景、回复历史、完成后补充回复及模拟折叠卡片不作为桌面常驻界面。无主界面、无托盘；最小化到任务栏，完成或取消销毁便签，最后一项任务结束后进程退出。缓存、CLI/MCP 和按需启动保持原协议。

原始演示和测试文件均排除在桌面发行包之外。`tests/Start-TestPlugins.ps1` 继续用于打开独立环境的三个测试插件；`release/config-ui-preview.json` 指向最新本地验收版。

验证：

```powershell
npm test
npm run test:rebuild
npm run test:native
npm run test:config-ui
npm run test:lifecycle
```

`test:rebuild` 使用真实 Electron、HTTP SPI 和 IPC，检查进度持久化、草稿保存提示、两侧插件操作、配置后执行、动效设置、四主题透明边缘、小窗口控制区、AI 更新后的草稿保留与转义，以及完成后关闭。截图和报告仅写入 `.qa/rebuild-*/`。

按验收反馈精简：删除顶部项目标签、底部保存/置顶文字和右下角缩放图标；四边与四角采用不可见的拖拽区域，以对应鼠标光标提示。原生端使用 DIP 指针坐标计算边缘缩放，保持对边锚定、最小尺寸和工作区限制，并持久化最终位置尺寸。底部左侧显示“等待你的反馈”，右侧只保留“完成并回复”。无文字时直接完成，已附图片仍然回传，不再显示“仅完成”按钮或其确认页。

回复区继续精简为完整输入框：不显示“回复”“草稿已保存”等标签或图片按钮；图片通过拖入和粘贴添加，附件仍可预览和移除。文本框取消原生 resize 手柄，默认输入高度约 64px，上下整条边缘可拖动调整；草稿后台保存，仅失败时提示。顶部标题栏可拖动窗口，四边四角仍可调整窗口大小。

回复框保留“写下结果，也可以直接粘贴图片…”占位提示；不预设大面积输入框，通过上下边缘调整输入区高度。

回复框下边拖动与窗口底边联动：下边下拉时，回复框和便签窗口等量增高，回复框上边位置不变；向上拖时一起缩短。上边拖动只调整内部回复高度，窗口大小不变。

v2.0.3 标题栏在最小化旁新增独立“×”关闭控件，沿用现有尺寸与主题令牌，悬停使用错误色提示取消当前协助。按钮有中文可访问名称、明确工具提示且排除原生拖动区。最小化继续等待；“×”、Alt+F4 与任务栏关闭经同一 preload/IPC 流程取消当前请求，其他便签不受影响。
